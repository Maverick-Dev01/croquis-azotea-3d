# Proyecto Croquis y Modelo 3D - Azotea (8m x 16m)

Visualizador interactivo 2D, modelo 3D en Three.js y render fotorrealista de proyecto de construcción y techumbre sobre losa existente de 8.00m x 16.00m.

## Características
- **Plano 2D Acotado:** Distribución técnica con cotas de muros, losas y techumbres.
- **Modelo 3D Interactivo:** Three.js con soporte táctil completo para celulares y computadoras.
- **Render HD Integrado:** Visualización fotorrealista del proyecto terminado.
- **Optimizado para Vercel:** Despliegue estático sin dependencias de build.

## Estructura
- `index.html`: Página principal con visor 2D, 3D y render HD.
- `vercel.json`: Configuración de enrutamiento y caché para Vercel.
- `render_3d_*.jpg`: Renders arquitectónicos en alta resolución.
